# Prospective Quote Lab

Read-only research branch. It is separate from main, v11, Kraken, Kalshi, and the existing early-wallet collector.

Purpose: build a prospective, outcome-independent opportunity registry and record time-stamped market observations plus amount-specific quote attempts. A quote is not a fill. Missing/late observations remain missing/late. No private keys, signing, or order submission.

The first version deliberately treats launch discovery and quote-provider support as measured capabilities. It must not call a DEX Screener mark an executable quote. It records provider failures and unsupported routes instead of deleting them.

Files under data/ are append-only checkpoints generated by the workflow. The initial discovery adapter uses PumpSwap program activity as candidate evidence and must validate mint/pool extraction before an opportunity is admitted. Wallet evidence is optional metadata and never rewrites an earlier decision.
